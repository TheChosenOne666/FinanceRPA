## 1. 市场调研：主流金融 RPA / 仪表盘设计风格

### 1.1 调研对象

| 平台/来源 | 关键设计特征 |
|-----------|-------------|
| **UiPath Assistant 2025** | 紧凑布局、命令面板、暗色主题、Pending/Unassigned/Completed 任务三分区、卡片式列表、清晰状态徽章 |
| **UiPath Studio 2025.10** | 全新视觉形象、紧凑功能区、超薄活动卡、面包屑导航、行号+断点、折叠逻辑块 |
| **影刀 RPA** | 双栏卡片式登录、占位符幽灵文字、ttkbootstrap morph 主题（毛玻璃）、企业 VI 定制、置顶半透明窗口 |
| **金融仪表盘（Clerio 等）** | 浅蓝主色调（可靠冷静）、绿/珊瑚红/黄辅助色、低饱和度、Urbanist 无衬线字体、模块化卡片、迷你图表、AI 助手聊天界面 |
| **B 端企业后台规范** | 蓝灰主色、状态色（绿成功/红失败/黄警告）、统一圆角边框阴影、8/16/24px 间距、斑马纹表格、骨架屏 |
| **2025 UI 趋势** | 暗色模式成标配、微交互（subtle）、玻璃态克制使用、极简功能深度、无障碍默认、数据驱动个性化 |

### 1.2 关键启示（指导本项目设计）

| 启示 | 应用到本项目 |
|------|-------------|
| 玻璃态要"克制使用"，不能全屏透明 | 仅卡片/弹窗/侧栏使用玻璃态，数据表格保持清晰可读 |
| 金融场景需要"可靠冷静"色调 | 深蓝主背景 + 浅蓝强调色，避免高饱和度 |
| 状态色必须清晰 | 绿（成功）/ 红（危险/拒绝）/ 黄（警告/待审批）/ 蓝（进行中）四色固定语义 |
| 数据可视化要简洁 | 避免 3D 图表，用折线/柱状/饼图，迷你 sparkline |
| 任务需要状态分区 | 任务列表按 pending/executing/needs_human/completed 分组 |
| 暗色模式是期望 | 默认暗色（液化玻璃态最佳载体），预留浅色切换 |
| 微交互要 subtle | 150-300ms 过渡，hover 用颜色/阴影而非 scale |

## 2. 设计风格：液化玻璃态（Liquid Glassmorphism）

### 2.1 风格定义

**液化玻璃态** = 传统 Glassmorphism + 液态有机感 + 多层光晕。区别于普通毛玻璃：

| 维度 | 普通毛玻璃 | 液化玻璃态（本项目） |
|------|-----------|---------------------|
| 边缘 | 规则圆角矩形 | 液态不规则圆角 + 大圆角（16-24px） |
| 背景 | 单层模糊 | 多层透明叠加 + 渐变光晕 |
| 光效 | 无 | 边缘霓虹光晕 + 顶部高光 |
| 色彩 | 静态 | 流动渐变（背景隐约可见） |
| 层次 | 2 层 | 3 层（背景模糊层 + 玻璃卡片层 + 高光层） |

### 2.2 视觉关键词

- **深邃**：深蓝近黑的背景，营造金融科技感
- **流动**：背景有微妙的渐变光斑（aurora 极光效果）
- **通透**：玻璃卡片半透明，背景若隐若现
- **光晕**：关键元素有边缘发光，强调焦点
- **克制**：数据区域保持清晰，不滥用透明

### 2.3 适用场景

| 场景 | 是否用玻璃态 | 说明 |
|------|:----------:|------|
| 登录页 | ✅ | 全屏玻璃态，营造第一印象 |
| 侧边导航栏 | ✅ | 半透明玻璃，背景透出 |
| 顶部导航栏 | ✅ | 玻璃态悬浮 |
| 卡片（KPI/概览） | ✅ | 玻璃卡片 |
| 弹窗/对话框 | ✅ | 玻璃态模态 |
| 数据表格 | ❌ | 保持实色背景确保可读 |
| 表单输入框 | ❌ | 实色背景，仅边框微透明 |
| 图表容器 | 🔶 | 外层玻璃卡片，图表本身实色 |

  box-shadow: 0 4px 16px rgba(0, 0, 0, 0.3),

/* 液态背景（极光） */

    radial-gradient(ellipse at 20% 30%, rgba(26, 43, 92, 0.6), transparent 50%),

    radial-gradient(ellipse at 50% 50%, rgba(45, 27, 78, 0.4), transparent 60%),

## 8. 待确认事项

在开始 HTML 开发前，请确认以下决策点：

| # | 决策点 | 我的建议 | 备选 |
|---|--------|----------|------|
| 1 | 默认主题 | 暗色（液化玻璃态最佳载体） | 浅色 / 双色切换 |

| 3 | 中文字体 | 思源黑体（兜底系统字体） | PingFang / Microsoft YaHei |
| 4 | 图标风格 | 手写 SVG stroke 线性图标 | filled 实心 / 混合 |
