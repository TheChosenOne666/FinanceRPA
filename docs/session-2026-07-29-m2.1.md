### 1. Skyvern 引入时机调整
- **原计划**：M2.1 Step 0 引入 Skyvern 源码

- **原因**：PlannerAgent 用 fallback 单步计划，ExecutorAgent 用 `_simulate_execution` 模拟执行，都不 import skyvern

- **全对齐方案**：M2.1 实现完整 Agent + LLM 模块（ActionCache/ModelRouter）→ 范围太大

- **折中方案（采纳）**：
  - M2.1 实现 Agent 三层骨架（Planner fallback + Executor + Coordinator）
  - M2.1 实现 Skills 基础层（BaseSkill + Registry + Pipeline）
  - M2.1 实现 demo_seed.py
  - ActionCache/ModelRouter/ResilientCaller 推迟到 M5
  - PlannerAgent LLM 版推迟到 M4.1
  - 外部接口稳定，内部实现分阶段替换
